# Projects

One folder per project: `activities/projects/<name>/`, with a `README.md` of 3 lines:

```markdown
**What:** one sentence about what it does.
**Who:** your name(s).
**Run / view:** the command to run it, or where to look.
```

Then open a pull request. See [`../open-ended.md`](../open-ended.md) for ideas.
